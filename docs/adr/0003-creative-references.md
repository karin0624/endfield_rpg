# 0003 参考作品を方向性の資料として扱う

- 記録日: 2026-09-24
- 状態: 採用

## 背景

企画・体験には『パワポケ12 裏サクセス 秘密結社編』、戦闘の見た目には『オクトパストラベラー』、行動順には『崩壊：スターレイル』、ルート選択には『Slay the Spire』が参考として挙げられた。

## 判断

これらは方向性を検討する資料として扱い、全システムや数式の再現を要件にしない。原作の文章や素材はコピーせず、試作用の内容を用意する。

## 結果

ゲームの振る舞いは参考作品から推測せず、[仕様概要](../../specs/overview.md)と各詳細仕様で定める。

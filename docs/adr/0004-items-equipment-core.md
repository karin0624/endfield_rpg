# 物品・装備を独立コアから接続する

日付: 2026-10-03

## 背景

ホームの在庫、探索へ持ち込む消耗品、探索で獲得した物品、持込みに属さない永続重要品では、移送・消費・喪失の条件が異なる。装備による能力値補正も、所持と割当ての方式から分離して検証できる必要がある。

## 判断

ホームストック、持込み／獲得バッグ、永続重要品を単純なデータとして分離する。装備は2枠と能力値投影だけを持ち、所有方式は利用可能IDの入力境界へ残す。当初の状態版・探索／報酬IDによる再送拒否は[ADR 0006](0006-synchronous-presentation-models.md)で廃止し、現在状態への同期入力へ置き換えた。数値は引数・定義として注入し、本編用の既定値を置かない。

全アイテムを同じバッグへ入れて例外フラグで保護する案は、重要品の「持込み自体がない」という意味を曖昧にするため採らない。装備効果DSL・売却経済・素材の物語・合成は作らない。抽選方法を先に固定する案も採らず、既存ゲーム乱数を使う方針の注入境界だけを作る。

## 結果

コアの利用契約と本編の接続は[物品仕様](../../specs/items.md)へ置く。ストック・バッグ・重要品を独立して検証し、探索の開始・帰還では他のゲーム結果と同じ確定処理へ接続する。表示側は確定した回復結果を受け取り、効果・疲労・時計を再計算しない。

数値・所有・抽選の具体的な選択は[ADR 0005](0005-approved-item-settings.md)で扱う。比較段階の提案値を現在の仕様として残さない。

# 共通UIの適用一覧

画面の設計方法は[画面設計](screens-and-patterns.md)、共通構造は[共通部品](components.md)、表現は[基本デザイン](foundations.md)、共通部品の実装値は[`ui.css`](../../src/web/ui.css)。本書は共通部品の接続・適用状況を管理する。「適用」は完成画像への一致やユーザー承認を意味しない。UI変更の採否は[承認とpixel diffの必須ゲート](production-and-validation.md#ui開発の必須ゲート)で別途確認する。画面を適用したPRでこの表と実画面証跡を更新する。

| 画面 | 共通部品 | 状況・残る範囲 |
| --- | --- | --- |
| ホームからの編成 | `ui-screen`、`ui-title`、`ui-actions`、`ui-button` | 適用。編集専用で出発なし |
| ダンジョン出発準備 | 同上、`ui-primary` | 適用。実出発だけに主操作を表示 |
| 仲間選択 | 同上、セージ選択と白focus | 適用。候補の内部scroll、各カードのHP・詳細・症状、選択番号。背景・人物・文字・材質のpixel diffは未解消 |
| キャラ詳細 | `ui-dialog`、`ui-title`、`ui-back` | 適用。表示専用、候補の状態を保持して戻る |
| デバッグ街からの編成 | 編成と同じview/model | 適用。直接出発する文脈と旧入口の責務を保持 |
| タイトル・ホーム・探索先 | `campaign.css`の既存部品 | 未適用。新案は目的・情報・操作から設計し、旧配置や共通骨格への移行を自動要件にしない |
| 街の場所選択・会話 | `style.css`の既存部品 | 未適用。静的場所選択と動的会話は別対象として設計し、既存背景・配置を新案の制約にしない |
| 装備・ショップ・物品 | `items.css`等の既存部品 | 未適用。既存の装備・ショップの操作と保存契約を保持。独立した物品一覧の完成を意味しない |
| ルート・成長選択 | 既存部品 | 未適用。地図配置と必須選択の仕様を保つ |
| 戦闘・戦闘詳細 | `style.css` / `battleSequence.css` | 新しい画面骨格は未適用。投影札・行動順は全画面アンカーの例外。戦闘演出のCSSは変更しない |

この表は現状の接続を記録する。次の画面の配置や意匠の採用を決めるものではない。役割と承認意匠が同じ部品は既存のクラス・トークンを再利用し、旧画面を未検証で一括変更しない。新しい対象の設計・承認は[制作手順](production-and-validation.md)に従う。

## 接続と検証への参照

編成の編集／出発文脈と所有境界は[共通部品の接続契約](components.md#編成の接続契約)、現在の画面操作は[編成仕様](../../specs/party.md)を参照する。旧API名を現行接続の正本にしない。

適用後の確認方法と`review:party`は[テスト設計](../testing.md)、固定版と許可領域は[承認記録](../ui-concepts/approved/README.md)、実画面記録は[編成の画面記録](../visual-records/formation/README.md)、素材の関係は[素材メモ](../../art-src/README.md)を参照する。本書へ検証手順・進捗を複製しない。

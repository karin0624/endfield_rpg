# 街

場所または人物を選び、街の活動を始める静的な画面。動的な会話・購入とは別の対象。[拠点部品仕様](hub-components.md)と[共通DS](../design-guidelines.md)を参照する。

## 全パーツと配置

| 要素 | 割当 | 用途・基準anchor |
| --- | --- | --- |
| 背景 | `town.png`、装飾画像 | 場所・人物と入口の位置関係を示す |
| 酒場 | PlaceEntry／施設、`tavern`図案＋吹き出し＋label | `guild`の入口。(270,325) |
| 広場 | PlaceEntry／施設、`fountain`図案＋吹き出し＋label | `town-square`の入口。(995,440) |
| 市場 | PlaceEntry／施設、`market`図案＋吹き出し＋label | `market`の入口。(1605,390) |
| ギルベルタ | PlaceEntry／人物、portrait＋吹き出し＋label | `find-companion`の入口。(1175,798) |
| ホーム | IllustratedAction／移動、`house`図案 | 場所としてのホームへ移動。履歴の戻る記号へ置換しない |
| 日付 | PassiveStatus／日付 | 日数・昼夜の確認 |
| メニュー | Button／メニュー | タイトルへのsystem操作 |
| 活動結果 | Feedback | 非空時だけ回復・加入等の既存結果を示す |
| system確認 | Dialog | タイトル選択・破棄確認。会話の意匠とは分ける |

利用できる場所は投影データに従う。実装IDとプレイヤー向け名称を混同せず、`guild`を表示するために「冒険者ギルド」という別ラベルを加えない。anchorは図案中心に対応する基準座標で、背景cover変換を通す。人物の顔用途viewportを施設の図案へ流用せず、市場等の全輪郭を保持する。

wideでは入口を背景上に置き、ホームと日付は右下、メニューは右上、結果は左下に配置する。compactでは結果→メニュー→場所群→ホーム→日付の通常flow。文字や図案、枠の全周と隣接関係を確認する。静的画面へ会話本文・話者・選択肢を常設しない。

## 操作と確定点

| 入力 | 結果 | 保持・復帰 |
| --- | --- | --- |
| 場所／人物 | 許可される活動を開始し、持込みを反映 | プレビュー選択＋別実行ボタンという段階を追加しない。会話完了後は街と元の場所へfocus |
| ホーム／静的画面のEsc | 活動中でなければ[ホーム](home.md)へ | 出かけるへfocus。閲覧終了だけで半日・回復・購入を加えない |
| メニュー | タイトルへの操作を表示 | 保存は無効で「保存はホームで行えます。」を説明。最初の有効commandへfocus |
| メニューの閉じる／Esc／外側 | 街の通常画面へ | メニューへfocus |
| タイトル選択・破棄確認の取消／Esc | 街へ | 現在状態を保持、メニューへfocus。確認の外側クリックは無視 |
| 活動中のsystem・帰還 | 受理しない | 会話途中の無消費取消や保存を新設しない |

会話の終了時に街活動の半日・回復等を一度確定し、街へ復帰する。買物を閉じることと活動完了を混同しない。購入ごとの半日は加えず、装備変更はホームの契約を保つ。詳細は[会話](../../specs/adventure.md)、[時間](../../specs/time.md)、[物品](../../specs/items.md)、[保存](../../specs/save.md)を正本とする。

通常面の読む順は非空結果→場所群→ホーム→日付→メニュー、compactはメニューを場所群の前へ置く。受動日付・通常statusはTabに含めず、scrollする結果のみregionとして到達可能にする。既定focusは既存の場所、活動完了後は元の場所。未解放、活動中、非空結果、system確認、長文、昼夜、compact・文字拡大を確認対象へ対応付ける。

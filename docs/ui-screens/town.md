## 配置・大きさ・原参考との関係

wideはwidth>900、height>650、横画面で実部品が衝突しない場合。1920×1080・root16時、world配置anchorは酒場(270,325)、広場(995,440)、市場(1605,390)、ギルベルタ(1175,798)。現行captureの人物と帰還の操作外形間隔は26.578125px、一方のfocus6pxを含めた残りは20.578125pxである。元背景上の場所・人物入口との関係を比較の出発点として保持し、labelと全actionboxが別地点・背景重要部分を隠さないか新全体画像で検証する。fontとglyphはviewportと一括縮小しない。

場所・本人の4点は原town1672×941に対する画像anchorである。上の1920比較点を共通DSのcentered coverの逆変換で原画像点へ戻し、別viewportではcropを含む順変換で配置anchorへ置く。viewport百分率や1920の絶対値へ置換しない。menu・帰還・日付はviewport端のanchorのまま扱う。各actionbox＋focus6が画面内へ入り、全群との1rem以上の間隔が保てる場合だけwideとし、市場等がcropで画面端へ出るときはcompact flowへ切り替える。

非空の活動結果はwideで左3rem・下1.75rem（root16で48,28）、幅はmin(32rem, viewport内の余裕)、高さは共通Feedback panel。場所4点、帰還、日付、menuのbox＋focusと1rem以上離す。長文／root拡大で衝突する場合はcompactの先に読めるflowへ切り替え、activity入口や原人物を隠す重ね置きで解消しない。内部scrollが必要な場合だけ「活動の結果」という名前付きregionをTab順の先頭へ追加する。結果が空なら領域とTab先を作らない。

メニュー右48・上28は保持する。最新の帰還・日付は右下の同じ群として端24px、間隔16px。帰還の可視名「ホーム」は帰還先を示し、長い操作名の一字折返しを避ける。accessible nameと既存moveHome操作は「ホームへ戻る」の意味を保持する。旧utility152×176・house80と旧calendar176×220はv20固定exportの履歴であり、現行規格へ重ねない。

compact条件はホームと同じ。上の通常flowにmenu、活動は施設3個→本人1個の読む順でinset16・gap16のgrid、2列が入れば2列、入らなければ1列。帰還＋受動日付は別群でwrap、通知は結果が必要なときだけ前に読めるflowへ。狭幅でworld anchorsを保持するため文字を縮めず、全入口へscrollできる構成を選ぶ。背景との位置対応がwideと変わる範囲は別の意匠検証対象。toolbar／rail／常設会話面／場所番号は追加しない。

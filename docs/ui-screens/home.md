# ホーム

管理、任意の出発準備、保存を行う拠点。街の場所選択とは別の画面であり、背景は提供された部屋の原画像を使う。特定都市の再現や、全地域共通の建築規則へ拡張しない。[拠点部品仕様](hub-components.md)と[共通DS](../design-guidelines.md)を併用する。

デザインマスタは[endfield-rpg.fig](../../art-src/openpencil/endfield-rpg.fig)の`Screens / Home`。色・文字スタイルと部品を分離し、画面ではインスタンスを使う。[OpenPencilの起動・保存手順](../../README.md#openpencilでデザインマスターを編集する)を参照する。

## 構成と適用理由

| 要素 | 割当 | 必要性・配置 |
| --- | --- | --- |
| 背景 | `home.png`、装飾画像 | 部屋の場面を示す。立ち絵は置かず、中央の空間を保つ |
| 仲間 | IllustratedAction／管理、`companions`図案 | 仲間管理への入口。現在は既存の全加入者装備一覧へ接続 |
| アイテム | IllustratedAction／管理、`items`図案 | 物品管理への入口の表示。現在は未接続 |
| 出かける | IllustratedAction／移動、`map-icon`図案 | 任意準備から行き先へ進む |
| 日付 | PassiveStatus／日付 | 日数と昼夜の確認 |
| メニュー | Button／メニュー | 保存とタイトルへの入口 |
| 結果 | Feedback | 帰還や保存等の既存結果がある時だけ表示 |
| 準備・確認 | Field／Button／Dialog | 数量、任意編集、保存・破棄の確定を通常面から分離 |

wideでは管理入口を仲間→アイテムの横1列とし、画面左24px・下32px、入口間16px。2個の外形は幅560px・高さ88px。移動ボタンの下位置も32pxに揃える。編成や装備専用の常設入口を追加しない。日付と移動の整列は[文字直下の線](hub-components.md#日付)を使う。

「仲間」は新しい人物一覧・詳細の完成を意味しない。「アイテム」は表示と機能完成を分ける。未接続の説明をゲーム画面へ追加したり、完成時の見た目を無効状態へ変更したりしない。準備・装備・編成・保存の既存機能を保持し、新機能や子画面の意匠は別の設計対象とする。

## 操作と確定点

| 入力 | 結果 | 保持・戻り・focus |
| --- | --- | --- |
| 仲間 | 既存装備一覧を開く | 戻ると仲間へfocus。装備変更の確定とHPへの影響は[物品仕様](../../specs/items.md) |
| アイテム | 現在は意味イベントへの接続なし | focus・外観の確認を、動作試験の成功に数えない |
| 出かける | 任意準備を開く | 有効draftなら行き先へ、不正なら数量へfocus |
| 持込み入力 | draftを更新 | 0は持込みなし。空、不正整数、保管超過は行き先確定時に拒否。入力だけでは在庫を動かさない |
| 準備の装備／編成 | 既存編集画面を開く | 有効・不正を問わず数量draftを保持し、準備の元操作へ戻る。編成は編集文脈で出発なし |
| 行き先へ | 有効draftで[探索先](map.md)を開く | 画面移動で時間・在庫を消費しない |
| 準備の戻る／Esc | 通常ホームへ | draftと確定済み編集を保持、出かけるへfocus |
| メニュー | 保存／タイトルを選ぶdialog | 最初の有効commandへfocus。閉じる・Esc・外側クリックで取消、メニューへ復元 |
| 保存／保存してタイトルへ | 上書き確認後に保存I/O | 取消を初期focus。保存成功後だけ完了／タイトルへ。失敗は現在状態と旧保存を保持 |
| 保存せずタイトルへ | 破棄確認後にタイトルへ | 取消／Escはホームと現在状態を保持 |

確認dialogの外側クリックは無視し、保存待機中は取消・再確定を受理しない。初期focus、Tab範囲、背面抑止は[CampaignHub](../../src/web/components/CampaignHub/CampaignHub.svelte)、状態は[campaignModel](../../src/presentation/campaignModel.ts)を参照する。時間・所持・保存の規則は[時間](../../specs/time.md)、[物品](../../specs/items.md)、[保存](../../specs/save.md)を正本とする。

## 読む順と復帰

wideは非空結果→仲間→アイテム→出かける→日付→メニュー、compactは非空結果→メニュー→仲間→アイテム→出かける→日付。Tabは受動日付と通常statusを除いたDOM順。結果がscroll可能なregionならTab対象にする。

既定入場は仲間、地図close・街からの帰還・ダンジョン帰還は出かける、装備からの復帰は仲間、system取消・保存成功／失敗はメニューへfocus。帰還結果の表示で入力先を通知へ移さず、focusのためにゲームの帰還処理を再実行しない。通常面には独自のTab循環を設けない。

準備は数量→装備→編成→行き先へ→ホームへ戻るの順。初期値0のまま進め、管理や編成を必須にしない。長い理由、保存失敗、数量不正、非空結果、compact・文字拡大を[部品の確認対象](hub-components.md#確認対象)へ対応付ける。

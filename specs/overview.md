# 仕様概要

この文書はゲーム全体の要件と責務境界を定める。詳細は各仕様を参照する。

## 全体の要件

| 項目 | 方針 |
| --- | --- |
| 実行環境 | ブラウザ |
| 戦闘 | 速度によるタイムライン式。順番が来た味方ごとに行動を選択し、入力中は論理時刻が止まる。ラウンド冒頭に全員分をまとめて入力する方式ではない |
| 街・拠点 | 場所を選ぶADV形式。会話、選択肢、フラグによるイベント分岐を扱う |
| ダンジョン | [固定ルート仕様](dungeon.md)に従って分岐・合流のあるノードを選択する。キャラクターを歩かせる探索は作らない |
| 戦闘画面 | キャラ・敵は2D、地面は3D、遠景は2D背景画像。立体的な床とカメラ表現を使う。背景全体の3D化は不要 |

原作の文章や素材をコピーせず、試作用の内容を用意する。

## 責務境界

技術構成と各ディレクトリの責務は次のとおり。

| 領域 | 構成 |
| --- | --- |
| ゲーム本体 | `src/game/`に状態・ルール、`src/content/`に型付きの定義データを置く |
| ブラウザ | `src/web/`にBabylon.jsの描画と入力・演出・保存I/Oを置く |
| 画面UI | 会話・街・戦闘コマンドはHTML/CSS。ルート図はHTMLボタンと必要に応じたSVG |

### ゲーム本体と表示の境界

ゲーム本体は通常のオブジェクト・配列と同期処理で「状態＋操作→次の状態＋出来事」を扱う。DOM・描画エンジン・通信・実時間・保存I/Oから独立させ、描画オブジェクトをゲーム状態に持たせない。

ブラウザとテストは同じゲーム本体を使う。UIは確定済みの結果を表示し、ゲームルールや論理状態の別の正本を持たない。演出用の一時状態は持てるが、演出終了をルール確定の条件にしない。

乱数が必要になった場合はゲーム状態に乱数状態を保持し、同じ初期状態・操作列で結果を再現できるようにする。演出用乱数とは分ける。

## 試作の範囲

試作の対象は次のとおり。

| 項目 | 仕様 |
| --- | --- |
| 編成・戦闘 | 味方2人・敵2体、通常攻撃のみ。固定ダメージ、命中・防御・乱数なし。詳細は[戦闘仕様](battle.md) |
| 行動順 | 戦闘中は速度固定。行動間隔と同時刻の優先順位は[戦闘仕様](battle.md)に従う |
| 探索 | [ダンジョン仕様](dungeon.md)に従う分岐と合流を含む手書きの固定ルート1つ。探索中のHP・戦闘不能を次戦へ引き継ぐ |
| 依頼 | 依頼1本。成功後の報告で固定報酬を1回だけ得る。失敗時は報酬なしで再受注可。帰還時に全回復する |
| 保存 | 街の通常画面で1スロット保存。会話・戦闘・探索途中の保存はしない |
| 会話表示 | 本文は一括表示。バックログ、既読管理、オート再生、ボイスは試作の対象外 |
| カメラ・構図 | 地面モデルと遠景画像の組み合わせごとに構図設定を持つ。現在の画面と設定は[画面仕様](visuals.md)に従う |

## 使用素材

画面での配置は[画面仕様](visuals.md)、出典と利用条件は[素材メモ](../art-src/README.md)を参照する。

| 素材 | 使用方法 |
| --- | --- |
| 主人公 | 斜め左前の透過PNGを表示する |
| 地面 | テクスチャを内包したGLBを表示する |
| 遠景 | 2138×736の背景画像を垂直な板に貼り、地面の奥に重ねる |
| 敵 | ブルースライムを表示する |

実行用は`public/assets/`、未使用の方向画像は`art-src/`に置く。

## 対象外

製品版の戦闘数式・バランス、技、速度変更・行動順操作、仲間イベント、装備・報酬体系、ルート自動生成、短編の分量・結末、音・演出、対象ブラウザの範囲、配信先・頒布方法はこの仕様の対象外。

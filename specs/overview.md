# 仕様概要

この文書はゲーム全体の要件と責務境界を定める。詳細は各仕様を参照する。

## 全体の要件

| 項目 | 方針 |
| --- | --- |
| 実行環境 | ブラウザ |
| 戦闘 | 速度によるタイムライン式。順番が来た味方ごとに行動を選択し、入力中は論理時刻が止まる。ラウンド冒頭に全員分をまとめて入力する方式ではない |
| 街・拠点 | 場所を選ぶADV形式。会話、選択肢、フラグによるイベント分岐を扱う |
| ダンジョン | [固定ルート仕様](dungeon.md)に従って分岐・合流のあるノードを選択する。キャラクターを歩かせる探索は作らない |
| 戦闘画面 | キャラ・敵は2D、地面は3D、遠景は2D背景画像。立体的な床とカメラ表現を使う。背景全体の3D化は不要 |

原作の文章や素材をコピーせず、試作用の内容を用意する。

## 責務境界

技術構成と各ディレクトリの責務は次のとおり。

| 領域 | 構成 |
| --- | --- |
| ゲーム本体 | `src/game/`に状態・ルール、`src/content/`に型付きの定義データを置く |
| ブラウザ | `src/web/`にBabylon.jsの描画と入力・演出・保存I/Oを置く |
| 画面UI | 会話・街・戦闘コマンドはHTML/CSS。ルート図はHTMLボタンと必要に応じたSVG |

### ゲーム本体と表示の境界

ゲーム本体は通常のオブジェクト・配列と同期処理で「状態＋操作→次の状態＋出来事」を扱う。DOM・描画エンジン・通信・実時間・保存I/Oから独立させ、描画オブジェクトをゲーム状態に持たせない。

ブラウザとテストは同じゲーム本体を使う。UIは確定済みの結果を表示し、ゲームルールや論理状態の別の正本を持たない。演出用の一時状態は持てるが、演出終了をルール確定の条件にしない。

乱数が必要になった場合はゲーム状態に乱数状態を保持し、同じ初期状態・操作列で結果を再現できるようにする。演出用乱数とは分ける。

## 試作の範囲

試作の対象は次のとおり。

| 項目 | 仕様 |
| --- | --- |
| 編成・戦闘 | [仲間・編成仕様](party.md)に従う4枠・空き枠可PT。初期仲間はロッシのみで単独出撃可。固定2対2は独立した戦闘デモ。詳細は[戦闘仕様](battle.md) |
| 行動順 | 戦闘中は速度固定。行動間隔と同時刻の優先順位は[戦闘仕様](battle.md)に従う |
| 探索 | [ダンジョン仕様](dungeon.md)に従う分岐と合流を含む手書きの固定ルート1つ。探索中のHP・戦闘不能を次戦へ引き継ぐ |
| 生活ループ | 街探索で仲間を増やし、同じセッションで編成→探索→帰還→街での療養を繰り返す。街・編成・ルートに日数と昼夜、街に回復結果、編成に持続症状と残り街探索回数を示す。街探索1回とダンジョン1回全体は各半日。昼→夜→翌日昼と進む |
| 帰還 | 探索内のレベル・経験値・後天習得スキル・成長補正を初期化し、状態異常補正込みの有効最大HPまで回復する。仲間・PT・フラグ・日数・ゲーム用乱数・症状・精神疲労・回復状態は巻き戻さない |
| 保存 | 街の通常画面で1スロット保存。仲間・PT・症状・回復状態・日数・乱数を保持する。会話・戦闘・探索途中の保存はしない |
| 会話表示 | 本文は一括表示。バックログ、既読管理、オート再生、ボイスは試作の対象外 |
| カメラ・構図 | 地面モデルと遠景画像の組み合わせごとに構図設定を持つ。現在の画面と設定は[画面仕様](visuals.md)に従う |

## 回復・探索育成の境界

生活時計と回復用の街滞在時間は分ける。暫定の生活時計接続では街探索完了だけが回復対象の半日を進め、ダンジョン内部のノード・戦闘・会話、編成・保存・再描画では進めない。ダンジョン全体の半日は帰還時に1回だけ計上し、療養へ算入しない。

肉体疲労・朦朧は同種発症でなし→軽度→中度→重度と1段階悪化し、街半日で逆順に1段階軽快する。肉体疲労の最大HP倍率は0.75／0.50／0.25、朦朧の命中率倍率は0.9／0.8／0.7。戦闘不能はHPと独立し、HP満タンでも戦闘参加不可、街6半日で解除する。

探索中に経験値を得てレベルごとにランダム3択からスキルを習得する。到達レベルが10の倍数なら最上位、その他5の倍数なら上位、それ以外は通常候補。帰還で探索育成を初期化する。

精神疲労の正本は連続した数値とし、ペナルティと回復はその値に基づいて滑らかに変わる。段階名は数値から派生する表示で、独立した回復状態を持たない。街行動の途中回復も数値に残り、区間下限へ揃えない。曲線・回復量・表示閾値は[状態異常](status.md)に試用値を定める。疲労増加が正のアクティブ効果だけに使用前倍率を適用し、通常攻撃は減衰しない。具体的な最終バランスは未確定。離散した街行動単位で回復する場合、完全回復までの行動数には境界が残る。

肉体疲労・朦朧の段階制と戦闘不能は精神疲労の連続数値と分け、[状態異常](status.md)の暫定規則に従う。精神疲労による追加発症の候補から戦闘不能を除外し、選ばれた症状へ一段階付与する。発症率・候補選択は精神疲労側の責務とし、追加発症判定は接続しない。

詳細の担当と実装順は[段階別計画](../docs/milestones.md)に分ける。HP端数・候補群等の未確定値は、確定事項と区別した試用値として担当機能の追加時に記録する。

## 使用素材

画面での配置は[画面仕様](visuals.md)、出典と利用条件は[素材メモ](../art-src/README.md)を参照する。

| 素材 | 使用方法 |
| --- | --- |
| 主人公 | 斜め左前の透過PNGを表示する |
| 地面 | テクスチャを内包したGLBを表示する |
| 遠景 | 2138×736の背景画像を垂直な板に貼り、地面の奥に重ねる |
| 敵 | ブルースライムを表示する |

実行用は`public/assets/`、未使用の方向画像は`art-src/`に置く。

## 対象外

SP、恒久育成、休息マス、新しい治療／休養コマンド、装備・ショップ、終了日・マルチエンディング、コンテンツ量産、公開・配信契約・アプリ化は対象外。参考作品の全システム再現を要件にしない。

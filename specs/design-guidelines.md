# デザインガイドライン — 遠征譚 D.03

案Dを基に採用した、UIとAI生成アセットの共通基準。D.02の配色・配置を維持し、四面体マーカーの使用を絞った。ゲームルール・画面接続の実装を確定する文書ではない。戦闘仕様は[battle.md](battle.md)、構図は[visuals.md](visuals.md)、素材の出典は[素材メモ](../art-src/README.md)を参照。

## 1. コンセプト

> 未来の辺境を旅するための、静かなコマンドRPGの窓。煤色の平らな面と鈍い金属の細い罫線で物語の落ち着きを保ち、いま判断する対象だけを明確にする。

原作を連想させる工業・鉱物のモチーフと、縦型コマンドを持つRPGの落ち着きを両立する。背景やキャラクターを主役とし、UIの常設情報は静かに支える。大きな金色の面、厚いベベル、中世風の唐草、宝石、過剰なネオン、装飾だけの管理番号は足さない。

## 2. 色は順位ではなく役割で指定する

原始色 → 意味を持つトークン → 部品、の順で参照する。`primary`を文字色とボタン色に兼用しない。CSSの正本は[参照サンプルのトークン](design-samples/endfield-d.css)の`:root`。明るいレビュー画面の外枠はゲーム用テーマに含めない。

| 意味・CSS変数 | 色 | 用途 |
| --- | --- | --- |
| `surface.base` / `--surface-base` | `#232825` | 基調面。文字下地は不透明にする |
| `surface.hover` / `--surface-hover` | `#313B34` | ホバー面。HPトラックも同じ原始色 |
| `surface.selected` / `--surface-selected` | `#3C463E` | 選択中も暗い面を維持 |
| `surface.pressed` / `--surface-pressed` | `#171D19` | 押下・暗い外縁 |
| `text.primary` / `--text-primary` | `#ECE9DF` | 本文・コマンド・主要数値 |
| `text.secondary` / `--text-secondary` | `#B8C1B9` | 補足・単位・待機表示 |
| `trim.metal` / `--trim-metal` | `#B58A46` | 細い金属罫・選択枠。主文字の下地にしない |
| `data.hp` / `--data-hp` | `#91B9A8` | HPなど穏やかに読むデータ |
| `action.primary` / `--action-primary` | `#F0B84A` | 情報量の少ない確認・出撃画面の主操作 |
| `on-action.primary` / `--on-action-primary` | `#232825` | 琥珀色の主操作に載せる文字 |
| `selection.edge` / `--selection-edge` | `#F0B84A` | 対象マーカーの小面積の稜線 |
| `status.danger` / `--status-danger` | `#ED927F` | 危険表示用。ラベルや形も伴わせる |

補助文字は「別カテゴリーの色」ではなく文字階層。サイズ・配置・ラベルも併用する。ミントはHPに残し、目を引くために彩度を上げない。琥珀色の大きな塗りは情報量の少ない場面に限定する。旧`#C9B98F`と主文字を重ねる使い方は採用しない。

### コントラスト

通常文字は4.5:1以上、状態や操作を識別するために必要な非テキスト部分は隣接色と3:1以上を基準とする。装飾罫を含む全色の総当たりではなく、実際の前景と下地で判断する。[W3C：文字](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[非テキスト](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。

| 前景 / 下地 | コントラスト比 |
| --- | ---: |
| `#ECE9DF` / `#232825` | 12.33:1 |
| `#ECE9DF` / `#3C463E` | 8.09:1 |
| `#B8C1B9` / `#3C463E` | 5.32:1 |
| `#232825` / `#F0B84A` | 8.32:1 |
| `#91B9A8` / `#313B34` | 5.38:1 |
| `#B58A46` / `#3C463E` | 3.13:1 |
| `#F0B84A` / `#171D19` | 9.51:1 |

sRGBの相対輝度から算出し、小数第2位まで表示。合否は丸め前の値で比較する。旧`#ECE9DF` / `#C9B98F`は単色同士で1.60:1だが、半透明だった旧画面の実測値ではない。透過・画像背景を使う場合は合成後に再評価する。マーカーの内外縁の比率も、任意の背景に対する視認性の保証ではない。

## 3. 部品と配置

形は直角を基本とし、薄い二重罫・控えめな真鍮色で統一する。大きな角丸や立体的な盛り上がりは使わない。見出し・コマンドは控えめな明朝体、説明はゴシック体、行動値など比較する数値は等幅を基本とする。文字は画像に焼き込まない。

| 領域 | 配置・表現 |
| --- | --- |
| 行動順 | 左端の縦リスト。各項目の左にアイコン、右に残り行動値。現在は枠・暗い選択面・「行動中」で示す |
| コマンド | 右端の縦リスト。選択は暗い面と罫線。キーボードフォーカスは別の白い外枠 |
| 一時情報 | 上中央。スキル説明と攻撃通知で共用し、同時に積み重ねない。不要時は窓ごと消す |
| 味方状態 | 下部右寄せ。参照サイズ230×78px、間隔10px。追加枠は左へ展開。行動中は枠と文字 |
| 対象選択 | 横に並ぶ敵の上に四面体と暗い対象ラベル。キャラクターを覆わない |

通常・ホバー・押下・選択中・フォーカス・使用不可を用意する。選択とフォーカスは別の状態。使用不可は実際に操作を無効化し、鍵の印なども添える。色だけで状態を区別しない。

サンプルの1308×728pxは提供画像の比較基準であり、本体の解像度・アスペクト比の変更指示ではない。単純縮小をモバイル対応の完了条件にしない。本文・操作文字、キャラクターとの重なりは実際の表示サイズで確認する。

## 4. 四面体は「重要そうな場所」の飾りにしない

**同一ゲーム画面の全UIを通じ、原則1個・同時最大2個。2個を常に表示するという意味ではない。静止中もこの個数制限を適用する。**

| 場所・状態 | 四面体 |
| --- | --- |
| 行動順の現在項目 | なし。枠と「行動中」で十分 |
| 行動中の味方カード | なし。枠と状態ラベルで十分 |
| 攻撃・スキル・防御などのコマンド | なし。選択枠で十分 |
| スキル説明・攻撃通知 | なし。情報表示であり選択対象ではない |
| 敵の対象選択 | 選択対象の上に1個 |
| 防御・攻撃通知中など対象を選ばない状態 | 0個 |

枠で識別できる場所には重ねない。複数対象にも一体ずつ付けず、範囲枠などを使う。将来、枠だけでは分からない別の選択操作に使う場合も、画面全体で上限を守る。縦に並ぶ選択肢では左、横に並ぶ対象では上に置き、先端を対象へ向ける。本サンプルの縦コマンドに追加する許可ではない。

造形はユーザー提供の協約オリジニウム参考写真から、暗い三角面・等高線状の刻み・鉱物の稜線を抽出した簡略四面体。小さい表示では刻みを省き、暗い外縁と琥珀色の輪郭を優先する。平面のひし形を回すのではなく、3D頂点を投影して長軸周りに6秒で1周させる。形状見本は静止で併記してよいが、実画面の選択表示に転用して並べない。

回転は補助であり、低コントラストを動きで補わない。回転停止操作と`prefers-reduced-motion: reduce`を維持し、止まっていても選択対象が分かること。[W3C：停止操作](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html)、[動きを減らす設定](https://www.w3.org/WAI/WCAG22/Techniques/css/C39)。

## 5. AI生成アセットへの指示

文字・数値・状態・単純な枠・寸法はHTML/CSS/SVGで管理し、AI生成は追加の図案や質感に使う。ボタン一式を文字ごと生成し直さない。生成前に用途、表示サイズ、透過の要否、使ってよい色、状態差分、基準画像を指定する。

共通プロンプトのひな形：

> 未来の辺境を旅する、静かなコマンドRPG「遠征譚 D.03」用の［部品名］。表示サイズ［幅×高さpx］、背景［透過／指定色］。煤色の平らな面、細い二重罫、控えめな真鍮の縁。輪郭・線幅・余白は添付の採用サンプルに合わせる。使用トークンは［用途と色］。文字・数字・ロゴ・人物・風景を含めない。中世の装飾、宝石、厚い金縁、強い発光を追加しない。四面体マーカーは別部品であり、この部品には描かない。

四面体そのものを作る依頼だけは最後の一文を造形指定へ置き換える。生成結果のHEX値や寸法を信用せず、採用時にトークン色へ補正する。状態差分は同じ原画を基に作り、輪郭や余白を変えない。出典・利用条件は素材メモへ記録する。

## 6. 参照サンプルと確認

[HTMLサンプル](design-samples/endfield-d.html)をリポジトリごと取得してブラウザで開く。CSS・JavaScriptと既存の`specs/screenshots/battle-adopted.jpg`を相対参照し、外部配信サービスや追加ライブラリは不要。HTMLだけを切り離すと参照ファイルが不足する。ファイル表示を制限するブラウザでは、リポジトリルートから`python3 -m http.server 8000 --bind 127.0.0.1`を実行し、`http://127.0.0.1:8000/specs/design-samples/endfield-d.html`を開く。

背景の明暗・白黒、一時領域、味方2枠／4枠、対象切替、回転停止を確認できる。「テーマ・部品」の四面体は静止見本。攻撃以外のコマンド・HPは表示確認用で、戦闘コアへの接続や新機能の実装は含まない。通知は確認用に自動消去しない。

追加・変更時は次を確認する。

- 明暗背景・実表示サイズで読めること。実際の前景／下地のコントラストを再計算する。
- 全画面の四面体が同時2個以下であること。本サンプルでは対象選択中1個、それ以外0個。枠やラベルへの重複追加がないこと。
- キーボードフォーカス、使用不可、回転停止・OSの動きを減らす設定でも操作対象が分かること。
- 一時情報が重ならず、味方の追加でコマンドやキャラクターを覆わないこと。

この確認は配色とUI状態の検証であり、WCAG全項目への適合宣言ではない。新しいテーマへ変更するときも役割と個数制限は維持し、本書と参照サンプルを一緒に更新する。

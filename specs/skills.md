# スキル定義

定義の正本は [skillDefinitions.ts](../src/content/skillDefinitions.ts)、型・分類・参照検証と基礎効果計算は [skills.ts](../src/game/skills.ts)、探索内の取得操作は [skillAcquisition.ts](../src/game/skillAcquisition.ts) に置く。ゲーム本体だけで扱えるデータとし、使用操作・抽選・画面・保存から独立させる。

## 種別・効果・使用条件

全スキルにID・名称・説明・通常／上位／最上位の分類・効果を持たせる。アクティブ自身に強化ランクを持たせず、威力はキャラの能力値に依存する。アクティブは精神疲労増加量・使用場面・対象条件を持つ。パッシブは習得中の常時効果であり、使用場面・対象選択・精神疲労加算を持たない。

| 効果 | パラメータ | 場面・対象 |
| --- | --- | --- |
| アクティブ攻撃（damage） | amount＋参照能力値×coefficient：1発の基礎ダメージ。hitCount：対象ごとの回数（省略時1） | 戦闘、生存中の敵1体または敵全体 |
| アクティブHP回復（hp-recovery） | amount＋参照能力値×coefficient：基礎回復量 | 戦闘／分岐、生存中の味方1体（自分を含む） |
| パッシブ通常攻撃力補正（basic-attack-power-bonus） | rankAmounts：各ランクの通常攻撃ダメージへの総加算量。アクティブの参照攻撃力へは加えない | 習得中の常時効果 |
| パッシブ攻撃力補正（attack-power-bonus） | rankAmounts：攻撃力への総加算量。通常攻撃と攻撃力参照アクティブへ反映 | 習得中の常時効果 |
| パッシブ最大HP補正（max-hp-bonus） | rankAmounts：症状補正前の最大HPへの総加算量。最大HP参照アクティブへ反映 | 習得中の常時効果 |

場面は battle／branch、対象は single-enemy／all-enemies／single-ally の閉じた識別子で表す。定義検証は未知の場面・対象や効果と条件の不整合を拒否する。実際の使用者・習得・対象の生存確認、HP上限や命中・行動消費の適用は使用処理が担当する。通常探索では定義に沿って通常攻撃・アクティブの参照能力値へ投影する。

## 精神疲労

使用時の精神疲労増加量は有限の非負数で、整数に限定しない。**増加量が正のアクティブだけ**が精神疲労による減衰対象になる。対象量は能力値から評価した基礎効果量（ダメージまたはHP回復量）とし、増加量そのものや他パラメータへ倍率を掛けない。増加量0のアクティブ、パッシブ、通常攻撃は対象外。減衰対象量は mentalFatigueAffectedQuantity から識別できる。

精神疲労の正本は連続した数値。使用前疲労 f、今回の増加量 Δ、基礎効果 B に対し、対象効果を B×m(f) で適用してから f+Δ へ更新し、その後に状態異常を計算する。今回増える疲労を今回の倍率へ先取りしない。同条件の次回は B×m(f+Δ) となる。パッシブ計算・再描画では加算しない。他種類の状態異常補正まで無効にする意味ではない。

倍率曲線・表示閾値・回復・追加発症と使用操作は精神疲労機能の責務。定義モジュールはそれらを実装せず、段階ラベルから倍率を決めない。非数値効果・異種効果の配列・全体回復は対象外。数値効果は端数を保持する。精神疲労は新規キャラで0、上限や使用禁止は設けない。

## 候補群と習得元

キャラと候補群の対応は独立した CharacterSkillProfile で管理する。ロッシ（player）とギルベルタは同じ検証用候補群 test-shared を参照する。到達レベルは2以上の安全な整数で、10の倍数を最優先して最上位、それ以外の5の倍数を上位、残りを通常とする。

| 到達レベル | 候補分類 |
| --- | --- |
| 2・4・6 | 通常 |
| 5・15・25 | 上位 |
| 10・20・30 | 最上位 |

各分類に重複しない候補を3つ以上置き、参照先スキルの分類を一致させる。習得済みアクティブ・上限到達パッシブ・保証解禁表にある技を除外すると、有効候補は3件未満になり得る。

初期習得と探索中の後天習得は LearnedSkill.origin の initial／expedition で区別する。取得経路 acquisition は initial／guaranteed／choice として別に記録する。初期パッシブはランク1。探索中に強化した初期パッシブも初期化でランク1へ戻り、保証されたレベル解禁も探索内の習得として除去する。

キャラ別 initialSkillIds の null は未決定であり、空配列とは異なる。探索取得コアは null を空ロードアウトへ変換せず開始を拒否する。通常探索ではロッシ・ギルベルタに仮の攻撃・回復アクティブを初期付与する。これはユーザー確定の技構成や原作の固有技ではない。呼び出し側は決定した初期スキルと初期レベルを渡す。保証解禁表 guaranteedUnlocks はキャラ別のスキルID・到達レベルで、アクティブだけを扱う。初期レベル以下の保証技は初期スキルとして定義し、重複・未知ID・不正レベルを拒否する。技一覧・解禁レベルは製品既定値を置かない。

## 探索内の取得・選択コア

createExplorationSkills は探索ID・既存ゲーム乱数状態・成長定義・カタログから状態を作る。探索IDは呼び出し側が探索ごとに一意にする。カタログには成長対象以外のキャラも含められる。成長対象のプロフィールと決定済み初期定義を必要とし、実際の仲間名簿との参照検証は接続側が validateSkillCatalog に名簿を渡して行う。定義は探索中に固定し、状態は公開操作の戻り値を引き継ぐ。保存データの読込検証はこのコアの責務ではない。

grantSkillExperience は既存 grantExperience の報酬再送防止・各到達レベルを利用する。選択権利の正本は growth.characters の pendingChoiceLevels だけであり、別の権利キューを作らない。複数キャラは成長定義の順、各キャラは到達レベル順に解決する。未選択権利がある間は次の経験値報酬を拒否する。

保証と抽選の細部について、現コアは次の暫定方式を扱う。これは最終バランスの決定ではない。

- 複数レベル跨ぎを含む各到達レベルで、定義済み保証技を抽選前に習得する。保証は選択権利を消費しない。
- 保証解禁表の技は解禁前も抽選対象に含めない。保証解禁と同レベルの3択は通常どおり残す。
- 3択は新規アクティブ、パッシブ習得、既習得パッシブの上限未満強化。パッシブの分類は元の候補群のままで、他分類へ昇格させない。
- prepareSkillChoice は先頭権利だけに重複しない3件を既存 nextGameRandom で抽選し、候補IDと更新後乱数を保持する。次の権利は前の選択後に生成するため、既習得・上限の判定は最新状態を使う。保持済み候補の参照・再準備・無効入力で再抽選しない。
- 有効候補が3件未満なら insufficient-candidates と空の提示を返し、権利・乱数を保持する。無断スキップ・上限超過・代替報酬は行わない。不足時は理由を表示して進行を停止する。試用データは帰還までの到達可能な全選択経路で不足を起こさない有限の候補群を持つ。
- chooseSkill は探索ID・対象キャラ・到達レベル・提示IDを照合し、1件だけ習得／強化して当該権利を消費する。解決済み・他キャラ・候補外・過去探索への入力は拒否する。

resetExplorationSkills はこの状態内の全キャラの成長と習得を初期定義へ戻し、権利・候補を除去して探索を閉じる。乱数と当該探索内の報酬受領記録は保持し、閉じた探索への入力を拒否する。新探索は新しいIDと引き継いだ乱数で明示的に開始する。取得コアは仲間・PT・HP・精神疲労・症状・残り療養時間・生活時計を所有しない。

## 効果定義と未接続の境界

activeSkillBaseAmount は amount＋指定した attackPower または maxHp×coefficient を端数処理せず返す。定義は有限の非負固定項と有限の正係数を持つ。これは能力値依存を検証するための最小の調整用形式であり、具体式・参照能力値・係数・端数処理の最終決定ではない。呼び出し側が成長と状態補正を反映した能力値を渡し、精神疲労減衰はその基礎効果へ使用前の値で適用する。

パッシブ rankAmounts の各要素はランクごとの総効果で、配列長がスキル個別の上限となる。passiveSkillAmount は1から個別上限までのランクの効果を返し、範囲外を拒否する。全スキル共通の無制限加算や、一律の増分にしない。通常攻撃専用加算、攻撃力加算、最大HP加算を区別し、参照能力値に該当する補正だけアクティブへ反映する。全効果・疲労増加量を自動強化しない。

通常操作の報酬・能力値投影・必須選択・帰還・保存は [成長接続](progression.md) に従う。選択画面は対象キャラ・到達レベル・現在レベルと余剰XP・3候補の効果を示し、パッシブだけ現在→次ランク／個別上限を示す。アクティブは新規取得と疲労増加量・使用場面を表示し、ランクを表示しない。保証取得は探索中の習得として案内する。Escでも必須選択を省略しない。選択後は次の権利、全完了後は元の街またはルートへ戻る。帰還・再出撃後の古い提示への入力は拒否する。

## 検証用データ

**全名称・固定項・参照能力値・係数・ランク上限と各段階効果・疲労増加量は仮の検証用であり、ユーザー確定値ではない。** 通常分類は初期攻撃・回復のほか、通常攻撃専用加算、攻撃力加算、最大HP加算、疲労増加なしの軽撃、低疲労の回復を持つ。初期2技を除いた5候補から抽選する。上位・最上位は攻撃・回復・パッシブの3候補を持つ。検証用データの正本は skillDefinitions.ts。攻撃は攻撃力、回復は最大HPを参照し、固定項と疲労増加量は通常＜上位＜最上位、通常攻撃力・最大HPパッシブは2ランク、攻撃力パッシブは3ランクを持つ。同種効果は型付きデータの追加と候補IDの登録で増やす。

検証は空・重複ID、未知ID、非有限・負の効果量と疲労増加量、不正な係数・参照能力値、空パッシブ上限、場面・対象・候補群・キャラ・初期スキル・保証解禁の参照や分類の不整合を拒否する。

SP、疲労回復スキル、汎用効果DSL、装備、編集GUIは扱わない。

## 通常探索の試用スキル操作

戦闘の「スキル」から仮の初期アクティブを選ぶ。単体攻撃は既存の敵選択、全体攻撃は生存中の敵全体を範囲として表示し、回復は自分を含む生存味方の選択で対象を指定し、「使用する」で確定する。「戻る」やEscは選択を閉じ、行動・HP・疲労・乱数を変更しない。

使用は通常攻撃と同じ一行動を消費し、既存の行動順で次の味方入力まで敵を進める。現在行動者・習得・使用場面・対象の生存と陣営を検証し、探索行動ID・戦闘ノードID・行動時刻が古い入力を拒否する。拒否は副作用を持たない。

攻撃スキルは通常攻撃と同じ朦朧補正後の命中率とゲーム乱数を使う。回復は暫定的に必中で、戦闘不能を復活させず対象の有効最大HPで止める。回復の基礎量は使用者の有効最大HPを参照する。成功した使用は外れや実回復0でも疲労を一度だけ加算する。その後、使用後疲労に基づいて使用者の追加発症を一度判定する。発症時の増加量は今回のスキル負荷から求める。詳細は[状態異常](status.md)に従う。

戦闘のスキル選択中は現在疲労の数値・派生ラベル、使用前倍率による予測効果、疲労増加、対象を表示する。予測は命中前・HP上限適用前の値。使用後は確定イベントの実HP変化量と使用前後疲労を表示し、使用後疲労から今回の効果を再計算しない。UIだけ小数第2位まで表示し、正本の値は丸めない。

分岐では「分岐で回復」から使用者→習得済みのbranch対応HP回復技→生存味方を選ぶと使用する。取消・Escは選択を閉じるだけで、元のボタンへフォーカスを戻す。必須習得選択・戦闘・会話・探索終了中は使用できない。控え、未習得、場面非対応、HP0または戦闘不能の使用者・対象を拒否する。回復は同じ基礎効果・疲労倍率・追加発症処理を使い、対象の症状を治療しない。自己回復は発症前のHP上限で適用し、使用者に症状が追加された後で必要なら低下した上限へ現在HPを収める。

分岐の入力は探索行動ID・現在ノードID・分岐使用版を照合する。有効使用だけが版を一つ進め、同じ入力の再送を拒否する。新しい版を使う意図的な再使用は同じ分岐でも可能。無効・取消・再送はHP・疲労・症状・乱数を変えない。ノード、フラグ、成長報酬、日数、街回復時計は進めない。使用結果は確定時の回復量と使用前後疲労・追加症状を表示し、次回の倍率から再計算しない。

## 多段・全体攻撃の定義と解決

攻撃の `effect.hitCount` は正の安全な整数で、未指定なら1回。`target: "single-enemy"` は選んだ敵1体、`target: "all-enemies"` は使用時に生存している敵全体を対象とする。全体の場合も回数は各対象へ適用する。攻撃はbattle専用で、回復への回数指定・全体回復・分岐攻撃は定義検証で拒否する。これは単一の数値効果を反復するデータ指定であり、汎用効果エンジンではない。

使用時の能力値・精神疲労・命中状態から1発の量と命中率を一度評価する。敵全体は戦闘開始時の定義配列順（ID順や画面の左右順ではない）、各対象内は1発目から昇順で解決する。各発・各対象を独立に命中判定し、必要な抽選だけをこの順に使う。途中でHPが0になった対象への残りは実行せず、その抽選も省く。単体攻撃を別の敵へ自動で振り替えない。

全対象・全発の後に疲労を1回加算し、追加発症判定を1回行い、1行動を完了する。使用後の肉体疲労による最大HP・朦朧による命中率の変更は今回の効果へ遡及しない。敵全滅後は敵の追撃を行わない。現行の本編catalog・初期所持・習得候補は単体1回のままで、runtime機能と本編への技の提供を区別する。

UIは1体・1発あたりの予測、回数、範囲と対象名、撃破時の打切りを示す。全体選択では単体マーカーを消し、生存敵の札を選択表示して個別の対象切替を止める。結果は各対象・各発の実量または外れを残し、疲労の前後は使用全体で一度表示する。
